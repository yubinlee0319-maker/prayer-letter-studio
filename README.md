# 기도편지 공방 (Prayer Letter Studio)

글과 사진을 넣으면 교회/선교 기도편지(소식지)를 만들어주는 정적 웹 앱입니다.
빌드 도구나 서버 없이, `index.html` 하나로 동작합니다.

## 기능
- 표지(제목·부제) + 표지 사진, 말씀 한 구절, 여는 글, 기도제목 항목을 입력하면
  실시간으로 카드형 소식지 미리보기를 생성
- 기도제목 항목마다 사진을 따로 첨부 가능 (콜라주로 표시)
- 이미지(PNG) / PDF로 저장 → 카카오톡 등으로 직접 전송
- 텍스트만 복사해서 붙여넣기
- 수신자 목록 관리 + 편지별 발송 체크리스트
- 데이터는 브라우저(localStorage)에 저장되며, JSON 백업 내보내기/가져오기 지원

## 사용 방법
`index.html`을 브라우저로 열거나, GitHub Pages로 배포한 링크에 접속하면 바로 사용할 수 있습니다.
별도의 설치나 로그인이 필요 없습니다.

## 참고
- 표지 사진을 올리지 않으면 기본 배경 이미지가 사용됩니다.
- 링크를 여러 사람과 공유해도 각자의 브라우저에 독립적으로 데이터가 저장되며,
  편지/수신자 목록은 서로 공유되지 않습니다.
